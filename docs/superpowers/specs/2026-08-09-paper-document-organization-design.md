# 论文文档整理设计

## 目标

将项目根目录中与论文直接相关的正文、草稿、Word 版本、排版审校产物和报告集中到 `paper/`，并在根目录提供 `文档索引.md`。代码、数据集、调试可视化图、实验脚本和已有开发计划不移动。

## 目录结构

```text
paper/
├─ 01_正文与草稿/
├─ 02_Word版本/
├─ 03_排版与审校/
├─ 04_审计报告/
└─ 05_临时文档/
文档索引.md
```

## 保留原位

- `README.md` 保持根目录位置。
- `tools/`、`tests/`、`docs/superpowers/plans/` 和 `docs/superpowers/specs/` 保持原位置。
- `debug_*` 调试目录和实验输入图片保持原位置；论文正式插图素材不属于调试输出，因此移动到 `paper/03_排版与审校/论文图表素材/`。
- `tupian/`、`debug_*`、项目源代码及其他实验资产保持原位置。
- 项目根目录之外的原始 Word 文件不在本次整理范围内。

## 路径兼容策略

移动前先扫描代码、测试和报告中的论文文件路径。对仍需运行的工具和测试，改用 `paper/` 下的新路径；报告中的历史文件名保留为文档标题，但链接指向新位置。不会修改算法逻辑，也不会覆盖用户已有的代码改动。

## 索引内容

根目录 `文档索引.md` 记录：文件分类、用途、版本关系、当前推荐版本、源文件和产物关系，以及最后整理日期。当前推荐阅读/提交底稿为 `paper/02_Word版本/基于机器视觉的游标卡尺自动读数识别系统设计2_算法一致性审校版.docx`。

## 安全与验收

整理采用同一工作区内的可恢复移动，不删除文件。移动后检查：

1. 所有目标文件存在且源位置不再重复保留。
2. 论文工具和论文相关测试中的路径可解析。
3. DOCX、PDF、Markdown 文件仍可正常打开或读取。
4. 索引中的每一项都能定位到实际文件。
