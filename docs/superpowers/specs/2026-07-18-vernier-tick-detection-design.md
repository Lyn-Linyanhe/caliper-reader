# 游标刻线检测修正设计

## 背景

当前算法的原始意图是：使用区域分割给出的游标刻线纵向带，对其做垂直投影；两个大谷底之间是完整游标刻线横向范围；范围内第一条真实刻线是游标零线。

现有实现保留了这个框架，但存在三个偏差：

1. 额外计算了游标本体横向范围，但检测函数没有使用该范围。
2. 谷底组合按从左到右顺序选择第一组宽松合格项，而不是选择图像证据最强的一组。
3. 投影候选、连通域匹配和去重结果使用不同数组表达，去重后可能发生索引错位；连通域信息也没有真正参与候选取舍。

## 目标

- 保留“两侧大谷底限定横向范围，第一条真实刻线为零线”的原始方法。
- 删除游标本体横向估算及相关无效参数。
- 使用图像中实际测得的投影周期、谷底和连通域证据选择范围及刻线。
- 修复重复峰、多识别、长刻线漏分类和调试曲线错位。
- 对无法可靠识别的图片返回明确诊断，不伪造刻线。

## 非目标

- 不强制拟合 51 条刻线。
- 不根据理论位置生成或补齐缺失刻线。
- 不生成标准化理论刻线曲线。
- 不按图片文件名或特定像素坐标增加特例。
- 本次不修改主尺 OCR 和最终读数合并逻辑。

## 数据流

```text
区域分割给出的游标刻线纵向带
  -> 二值前景与原始垂直投影
  -> 平滑投影并提取低响应谷底段
  -> 评价全部相邻左右谷底组合
  -> 选择图像证据最强的横向刻线范围
  -> 在范围内生成投影候选
  -> 将候选与唯一连通域证据绑定
  -> 根据实测周期抑制重复峰
  -> 保留最终真实候选，不补线
  -> 第一条候选作为零线
  -> 根据实测连通域下端位置分类长短刻线
```

## 设计

### 1. 删除横向本体估算

删除 `_find_vernier_body_x_range()`，并从 `_detect_vernier_band_projection()` 删除 `body_x1`、`body_x2` 参数。检测输入只使用区域分割产生的游标刻线纵向带，横向范围完全由谷底法决定。

同时删除仅为横向本体估算服务的代码。其他未调用的刻线连通性辅助函数不在本次清理范围内；实现时先判断它们能否用于候选证据，再决定保留或删除。

### 2. 选择两个大谷底

继续从平滑垂直投影中提取低于自适应阈值的连续谷底段，并合并距离很近的谷底段。谷底最小宽度相对当前图像中实测到的主周期设置，避免把单个噪声凹点当成边界。

不再遇到第一组满足条件的谷底对就返回。对所有有足够中间宽度的相邻左右谷底组合计算以下图像证据；不跨过中间谷底拼接多个重复网格：

- 左右谷底的深度和持续宽度。
- 两谷底之间投影峰的覆盖范围。
- 两谷底之间投影的实测主周期是否清晰。
- 候选相邻间距相对实测主周期的离散程度。
- 有独立竖直连通域证据的候选占比。

各项证据归一化到 0 至 1，初始评分定义为：谷底深度与宽度 30%、实测周期清晰度 30%、相邻间距一致性 25%、唯一连通域支持率 15%。权重集中放入配置，批量回归时统一调整，不允许按图片设置参数。选择总分最高的谷底对。这里不使用固定刻线数量，也不使用 51 条理论跨度。若最佳组合的实测周期清晰度低于 0.35，或总分低于 0.45，则返回“未找到可靠游标横向范围”，而不是选择第一组弱候选。

实测主周期来自两谷底之间原始投影的自相关峰，并以候选间距的稳健统计量进行交叉检查。它描述当前图片真实重复结构，不生成理论刻线位置。

### 3. 候选与连通域绑定

引入内部 `TickCandidate` 数据对象，至少包含：

- `x_projection`
- `projection_strength`
- `component_id`
- `component_height`
- `component_bottom_y`
- `component_area`
- `spacing_error`
- `accepted`
- `rejection_reason`

连通域只提取一次，每个连通域带稳定 ID。候选匹配后把证据复制到候选对象，不再维护与候选平行的 `component_matches` 数组。

匹配采用一对一约束。同一连通域不能支持两个候选；候选竞争同一连通域时，优先保留 x 距离更近、投影更强的候选。

连通域是证据，不是单独的真值：

- 有连通域支持的候选仍需通过局部间距检查。
- 没有连通域支持的候选不会立即删除；若它位于稳定的实测周期序列中，可作为弱候选保留。
- 主尺残留或边缘即使形成竖直连通域，也不能仅凭连通域进入最终结果。

### 4. 重复峰抑制

从选定区域的自相关和候选间距得到实测主周期。两个候选间距小于实测主周期的 0.65 倍时视为重复竞争项，并比较以下证据，只保留较强者：

1. 投影峰强度。
2. 是否具有唯一连通域支持。
3. 与左右相邻候选组成的间距连续性。
4. 连通域的竖直程度和接缝连接质量。

大于正常周期的空隙只记录为疑似漏检，不插入新候选。这样可删除 `100.86.jpg` 中 23 至 28 px 的半间距重复峰，同时不会自动补造刻线。

### 5. 零线定位

谷底范围和最终候选序列确认后，最左侧第一条被接受的真实候选就是游标零线。不增加 OCR、理论位置或吸附回退。

若最左候选置信度不足或其后无法形成稳定的实测周期序列，则本次零线识别失败，输出原因而不是退回任意第一峰。

### 6. 长短刻线分类

删除仅按 `长度 > 中位数 * 1.3` 的单阈值分类，也不使用“每五条必为长线”的理论周期。

先对具有有效连通域证据的最终候选，使用实际 `component_bottom_y` 做一维两组聚类，并以实际连通域高度交叉检查。两组中心距离至少达到短组中心的 20%，且每组至少包含两个候选时，较长的一组标记为长刻线。没有连通域匹配的候选可使用其自身实际测得的竖直笔画长度与这两个图像实测中心比较；不生成理论长度。无法形成可靠两组时全部标记为“长短不确定”，不强行分类。

调试图展示实际连通域下端响应和最终分类结果，不再绘制标准化理论曲线。

## 诊断输出

每张图片保留以下诊断信息：

- 全部谷底段及最终选中的谷底对。
- 每个谷底组合的图像证据评分。
- 实测主周期及周期清晰度。
- 原始候选数、去重后候选数。
- 每个候选的连通域 ID、接受状态和拒绝原因。
- 疑似漏检间隙，但不生成补线。
- 零线成功或失败原因。

可视化保留原始垂直投影和实际连通域下端曲线，新增最终接受/拒绝候选标记，删除标准化理论刻线曲线。

## 错误处理

- 少于两个可靠谷底段：返回横向范围识别失败。
- 所有谷底组合周期性都很弱：返回范围不可靠。
- 最终候选不足以建立稳定实测周期：返回刻线识别失败。
- 零线之后缺少稳定连续序列：返回零线识别失败。
- 长短两组无法可靠分离：保留刻线位置，长短状态设为不确定。

错误状态必须进入 `extra_info` 和调试可视化，不能以高置信度正常结果继续。

## 验证

重点回归样本：

- `100.00.jpg`：检查重复峰和长刻线漏分类。
- `100.60.jpg`：检查两个谷底和零线选择。
- `100.74.jpg`：检查长刻线分类。
- `100.86.jpg`：检查半间距重复峰和候选/连通域对齐。

完成后对 `tupian/` 全部图片重新生成：

- 主尺刻线可视化。
- 游标刻线可视化。
- 谷底组合与候选诊断。
- JSON 汇总。

验收不要求固定 51 条。验收依据是候选来自真实图像、无明显半周期重复峰、谷底范围正确、零线为范围内第一条真实刻线、连通域曲线与最终候选一一对应，并且失败样本明确报告失败。
