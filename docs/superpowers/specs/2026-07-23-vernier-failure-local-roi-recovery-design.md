# 游标失败时的局部 ROI 扩边恢复设计

## 目标

当紧凑读数 ROI 的游标识别明确返回 `no_reliable_valley_bounded_tick_range` 时，仅在原紧凑框与已检测游标本体框之间扩大必要的一侧边界，重新执行后续识别。正常识别路径与其 ROI 均不变。

## 边界

- 不使用文件名、真值、固定 51 条刻线、补线或理论刻线网格。
- 不将失败图直接回退为完整 `body` ROI。
- 候选只由当前图片已得到的 `compact` 和 `body` 框构造，保持原 y 范围不变。
- 仅游标错误为 `no_reliable_valley_bounded_tick_range` 时触发；区域分离、OCR 和其他游标错误不触发。

## 候选与选择

对紧凑 ROI 可扩展的左、右余量分别生成固定的局部候选：单边扩展三分之一、单边扩展三分之二，以及双边各扩展三分之一。候选按新增面积升序处理。

每个候选完整重跑预处理、方向校正、区域分离、主尺和游标识别。只有游标结果不带错误且具有当前算法要求的最小刻线数和零线时，才接受该候选。第一个合格候选被采用，因此结果仍使用最小的有效 ROI。

## 可观测性与验证

最终结果记录恢复是否触发、尝试过的候选及被采用的候选名。回归测试覆盖：

- 正常识别结果不构造或运行恢复候选。
- 失败时候选不越过 `body` 边界，并按面积排序。
- `22.00`、`30.00`、`33.00` 与 `80.90` 可通过恢复路径获得非零读数。
- `70.00`、`72.52`、`120.60` 等正常控制图的 ROI 来源和读数不改变。
