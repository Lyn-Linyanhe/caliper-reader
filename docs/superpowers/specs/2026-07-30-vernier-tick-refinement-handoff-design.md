# 游标刻线精细定位传递设计

## 目标

让游标刻线的局部细笔画测量结果成为最终灰度亚像素定位的搜索中心，避免最终坐标重新锚定到较粗的投影候选中心。

## 范围

只修改 `caliper/vernier_scale.py::_build_ticks_from_band_detection` 中单条刻线的坐标精细化衔接，以及对应单元测试。

不修改下列行为：

- 竖直投影产生游标刻线候选的位置和阈值；
- 连通域的提取、匹配、候选去重及谷底评分；
- 顶部细笔画检查、谷底范围、游标零线选择和主尺对齐；
- 任何理论刻线补全或固定刻线数量约束。

## 现状与问题

投影区段中心 `x_projection` 是候选位置。若候选没有连通域，`_refine_vernier_tick_from_band` 会在候选附近的细前景段中计算 `x_refined`。但随后 `refine_tick_x_subpixel` 仍使用 `x_projection` 作为中心，最终写出的 `x_precise` 因而没有继承局部细笔画定位。

这会使投影峰偏斜、较宽或含邻近前景时的局部修正失效。

## 设计

每条保留候选遵循固定坐标链：

```text
x_projection -> x_refined -> x_precise
```

其中：

- `x_projection` 继续只负责召回候选；
- `x_refined` 来自连通域接缝侧中心，或无连通域时的局部细笔画测量；
- `x_precise` 在灰度刻线带的接缝附近，围绕 `x_refined` 做现有的亚像素精修；
- 最终 `tick['x']`、`tick['x_precise']` 继续由 `x_precise` 导出；`tick['x_projection']` 保留原始候选，便于调试比较。

当无灰度刻线带时，最终位置回退到 `x_refined`，不再回退到 `x_projection`。

## 验证

新增单元测试构造“投影候选中心与细笔画真实中心不同”的窄刻线带，并替换亚像素函数以记录输入中心。测试必须先在旧逻辑失败，断言该函数收到的是 `x_refined`，而不是初始候选位置。

随后运行游标刻线、谷底、顶部笔画、标准曲线及对齐相关回归测试，保证正式候选数量、零线和读数路径未被主动改变。
