# 游标标准曲线长度聚类设计

## 目标

在详细模式既有的“游标刻度线”纵向合成图中增加一张长度标准化曲线。该曲线用于检查最终游标刻线的横向序列与长短结构，不参与候选提取、谷底评分、零线选择、对齐或最终读数。

## 范围与边界

- 修改 `caliper/vernier_scale.py` 的详细模式可视化生成。
- 不新增 GUI 标签页；曲线放在已有的游标刻线图中。
- 不修改 `recognize_vernier_scale` 返回的 `vernier_ticks`、`zero_x`、`alignment_info`、`vernier_reading` 或任何评分。
- 只使用最终已接受的 `vernier_ticks`，不使用 `rejected_candidates`、理论网格、补线或文件名。
- 不引入第三方聚类依赖；使用 NumPy 实现确定性一维两类聚类。

## 输入与输出

### 输入

- `vernier_ticks`：谷底范围、投影与连通域筛选后保留的实际刻线字典；每条包含 `x`、`x_projection`、`length`。
- `band_detection['x1']`：局部刻线带的全局 x 偏移。
- `band_w`：刻线带显示宽度。

### 输出

生成长度为 `band_w` 的 `float` 数组 `standard_response`：

- 短线簇成员的峰值振幅为 `1.0`。
- 长线簇成员的峰值振幅为 `1.5`。
- 无可靠长短分离时，所有峰值振幅为 `1.0`。
- 每个峰中心位于最终刻线的 `x_projection - x1`，横向高斯核固定覆盖 `[-3, 3]` 像素，`sigma=1.1`。
- 相邻峰重叠时取逐像素最大值，不累加。

输出仅传给可视化面板，不写入识别结果字典。

## 一维聚类算法

1. 从最终刻线读取有限且大于零的 `length`。少于 6 条时直接返回单类结果。
2. 计算长度的第 5、95 百分位，将每个长度截断到该闭区间，降低极端碎片或粘连长线对聚类中心的影响。
3. 用第 25、75 百分位作为两个初始中心，按距离分配样本并更新均值；最多迭代 20 次，中心变化小于 `1e-3 px` 时收敛。初始中心相同则返回单类。
4. 对最终中心排序，较小中心为短线簇，较大中心为长线簇。
5. 仅当以下条件同时满足时接受两类结果：
   - 两簇均至少 3 条刻线；
   - 中心间距 `long_center - short_center >= max(2 px, 0.20 * median(clipped_lengths))`；
   - 每簇内至少有一个原始长度样本，防止裁剪边界产生空簇。
6. 不满足任一条件时返回单类。所有刻线使用振幅 `1.0`，并在面板标题显示 `single length cluster`。
7. 满足条件时，短线使用振幅 `1.0`，长线使用振幅 `1.5`，标题显示两个中心、两个簇的数量和 `two length clusters`。

该算法只给已检测刻线分组，不会把任何空白位置变成刻线，也不会因期望有长线而强制形成两个簇。

## UI 布局

现有 `_draw_vernier_ticks_on_band` 的顺序为：刻线带叠加图、原始投影、接缝侧连通域响应。新增面板插入为：

```text
刻线带叠加图
Raw vertical projection
Seam-near component bottom position
Length-normalized standard response (short=1.0, long=1.5)
游标谷底选择图
游标连通域图
```

标准曲线使用当前绘图函数的 `1.0/1.5` 纵轴刻度，绿色竖线仍代表最终刻线位置。图标题必须说明当前为 `two length clusters` 或 `single length cluster`，防止将单类图误解为检测到了长短结构。

## 测试

1. 用合成长度 `[10, 11, 10, 11, 20, 21, 20, 21]` 验证产生两类、低簇为 `1.0`、高簇为 `1.5`。
2. 用近似一致长度 `[10, 10, 11, 10, 11, 10]` 验证拒绝两类并返回单类。
3. 用少于 6 条长度验证单类回退。
4. 用 `30.00.jpg` 详细模式回归，验证 `4b_游标刻度线` 的高度增加并包含标准曲线标题，同时 `total`、`zero_x`、`vernier_scale` 与修改前一致。
5. 运行 `tests/test_vernier_debug_panel.py`、新增聚类测试和离散对齐测试。

## 验收条件

- 详细模式游标页出现标准曲线；快速模式仍不生成该图。
- 曲线只引用最终已观察的游标刻线。
- 无明显长度分群时明确显示单类，不伪造长短线。
- 识别数值、零线和现有游标谷底/连通域诊断保持不变。
