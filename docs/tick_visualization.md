# 主尺与游标刻线可视化

## Pipeline 集成

刻线可视化只在非快速模式生成。

- 主尺：`recognize_main_scale(..., make_debug=True)` 生成 `vis_ticks`，由 pipeline 注册为 `3a_主尺刻度线`。
- 游标：`recognize_vernier_scale(..., make_debug=True)` 生成 `vis_ticks`，由 pipeline 注册为 `4b_游标刻度线`。
- 快速模式不生成这些图，不影响刻线检测和最终读数。

## 主尺刻线图

主尺图由灰度主尺区域、二值缩略图和三个纵向堆叠面板组成。

### 顶部图像

- 背景是方向校正后的主尺灰度图。
- 绿色半透明带是水平投影确定的主尺刻线带。
- 主尺刻线叠加在灰度图上，长刻线使用较亮的绿色并以青色圆点标记。
- 右下角显示实际用于检测的二值缩略图。

### 原始垂直投影

对主尺刻线带内的二值图按列统计前景像素，得到原始垂直投影。该曲线用于展示刻线候选出现前的原始响应；主尺候选本身由此类投影峰段检测得到。

### 接缝锚定纵向支撑

对每个 x，在主尺刻线带中寻找下端接近主尺/游标接缝的最长前景连续段。计算时允许一个缺失行，以降低二值化小断裂的影响。

- 曲线表示每个 x 的接缝锚定连续长度。
- 绿色竖线表示已检测到的主尺刻线候选。
- 该图用于检验候选是否确实由靠近接缝的刻线支持，而不是由上方数字或污点触发。

### 标准化刻线响应

在每个主尺候选的 `x +/- 2px` 范围测量接缝锚定支撑值。

1. 用所有候选支撑值的第 75 与第 85 百分位数平均值作为自适应长刻线阈值。
2. 低于阈值的候选映射为 `1.0`。
3. 高于或等于阈值的候选映射为 `1.5`。
4. 每个候选绘制为窄高斯峰。

标准化曲线只用于可视化和质量检查，不会补齐缺失刻线，也不会修改主尺刻线位置。

## 游标刻线图

游标图使用区域分离得到的游标刻线带，并在水平方向上通过两段相邻大谷底确定完整游标刻线范围。详细模式下，其输出由顶部图像、原始垂直投影、实际连通域下端响应、观测长度聚类标准曲线和逐刻线校正诊断面板组成。

游标模块会在区域分离得到的刻线带下边界额外保留 `16px` 测量余量。该余量用于容纳长游标刻线的下端，避免连通域高度被带边界裁切。

### 顶部窄刻线带

- 背景是用于游标刻线检测的同一张窄灰度刻线带。
- 橙色线是游标刻线候选，粗橙线标记第一条游标刻线，即游标零线。
- 顶部叠加使用最终接受候选的 x 参考线；它用于检查候选序列和长短分类。

### 原始垂直投影

对完整游标刻线带按列统计二值前景像素得到原始垂直投影。两个大谷底之间的投影峰段产生游标刻线候选；该步骤不使用理论网格，也不补线。

### 接缝附近连通域下端位置

镜头透视会使游标刻线轻微倾斜，因此不能用固定 x 列的连续像素长度表示刻线长度。当前实现对每个投影候选做局部连通域匹配：

1. 对扩展后的游标刻线带先做 `1x7` 竖直开运算，去除下方横线，再计算连通域。
2. 只保留接触刻线带上沿、足够高、足够细的组件。
3. 候选和组件进行一对一匹配；同一个组件不能支持两个候选。
4. 响应值取匹配组件的最低端坐标：`y_end`。

中层曲线显示最终候选各自绑定组件的最低端位置，绿色竖线表示最终接受的投影候选。候选去重后不再复用去重前的平行匹配数组，因此曲线位置与候选保持一一对应。

游标图不生成固定 51 条的标准化理论刻线曲线，但会生成一条只基于当前已接受刻线的观测长度聚类标准曲线。该曲线把可靠分离的短线簇显示为 1.0、长线簇显示为 1.5；样本不足或两簇不分离时显示单类。它只用于详细模式可视化和质量检查，不补造缺失刻线，不参与谷底、零线、对齐或最终读数。长短分类直接使用当前图像中实际组件下端位置的双组结构；两组无法可靠分离时保留刻线位置，并将长短状态标为不确定。

### 长度标准曲线与逐刻线校正

长度曲线的输入是最终接受游标候选的 `x_projection` 和 `length` 字段。实现采用
一维观测长度聚类，而不是按照理论周期生成峰。它的输出只是一维显示响应和聚类元数据，
不回写正式候选。

逐刻线校正面板从同一批投影候选出发，逐条追踪接缝侧细笔画，并以每条刻线自己的
接缝参考位置独立平移。由于每条线可以有不同斜率，该面板不能被解释为全局旋转校正。
当前校正后的带和投影仅用于诊断；正式识别仍使用原始游标带、原始候选、`x_precise`
和 `zero_x`。

## 读数与坐标边界

- 主尺和游标的投影候选、连通域高度均不用于补线或生成理论网格。
- 游标连通域提供稳定组件 ID、上下端、组件高度和下端位置，用于候选取舍、可视化与刻线元数据。
- `x_projection`、`x_refined`、`x_precise`、`length`、`component_bottom_y`、`x_top`、`x_bottom` 和 `fit_slope` 是后续标准化/逐线校正研究需要保留的刻线字段，即使某些校正结果当前不参与正式读数。
- 最终游标亚像素 x 坐标仍由灰度图在投影候选 x 附近进行精修；连通域接缝端 x 尚未作为该灰度精修的初值。
- 因此，当前可视化展示的是检测质量与几何响应，不能替代最终读数对齐图。

## 颜色约定

- 橙色：游标刻线候选或游标零线。
- 绿色：主尺候选线，或响应面板中的候选参考线。
- 黄色：接缝锚定主尺支撑、游标连通域高度响应。
- 蓝色：主尺标准化响应峰。
- 青色：主尺长刻线标记。
